# ILYA DIGITAL
Портфолио на HTML, CSS и JavaScript без сборки и зависимостей npm.

## Открыть на компьютере
1. Распакуйте весь ZIP через «Извлечь всё».
2. Откройте `dist/index.html` в браузере.
3. Для редактирования в VS Code: File → Open Folder → папка `ilya-digital`. ZIP как текст открывать не нужно.

Для локального сервера: `python -m http.server 8000 --directory dist`, затем http://localhost:8000.

## Страницы
- `dist/index.html` — портфолио, услуги, подход и составление брифа.
- `dist/services.html` — услуги и FAQ.
- `dist/projects/forma-wood.html`, `dist/projects/garage-74.html` — кейсы.
- `dist/demos/forma-wood/index.html`, `dist/demos/garage-74/index.html` — самостоятельные демосайты.

## Публикация после одобрения владельца
Подготовлено для одного репозитория `WarGenZOV/ilya-digital`.
Репозиторий и GitHub Pages ещё не созданы/не включены.
1. Создать публичный репозиторий `ilya-digital` и загрузить содержимое этой папки, включая `.github`.
2. Settings → Pages → Source: GitHub Actions.
3. Actions → Publish GitHub Pages → Run workflow.
Workflow запускается только вручную, автоматической публикации при push нет.
Все пути относительные и подходят для GitHub Pages в подпапке репозитория.

## Честное описание проектов
FORMA WOOD и ГАРАЖ 74 — самостоятельные демонстрационные проекты, не коммерческие заказы. Нет вымышленных метрик, клиентских отзывов и заявлений о выполненных заказах.
Изображения мастерской — визуальные ориентиры из исходного проекта, а не фотографии работ. Автомобиль — иллюстрация, созданная с помощью ИИ.
Названия и цены в демо условные. Формы не отправляют и не сохраняют данные. Бриф можно скопировать; при недоступном Clipboard API текст выделяется для ручного копирования. Карты автосервиса открывают поиск, а не адрес вымышленной организации.
Публичный контакт — профиль GitHub. Личная почта и телефон не добавлены.
Внешняя зависимость: Google Fonts, с системным запасным шрифтом.

## Проверка
См. QA.md. Публикация и проверка реального GitHub Pages выполняются отдельно после одобрения.

Важно: загружайте в корень репозитория содержимое папки ilya-digital, включая .github и dist, а не ZIP и не дополнительную внешнюю папку. Публикация выполняется вручную через Actions.
